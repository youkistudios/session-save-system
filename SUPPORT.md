# Support

Use GitHub Discussions for workflow questions and Issues for reproducible
defects. Use private vulnerability reporting for security-sensitive behavior.

Include the command used, operating system, shell, whether a custom
`SAVE_SYSTEM_HOME` or `CLAUDE_CONFIG_DIR` was set, and a synthetic directory
tree. Never post real session logs or secrets. This is a community-maintained
open-source project; response times are not guaranteed.
