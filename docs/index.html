Safety modelArchitectureEvidence

Five direct answers.

What does “session memory” mean here?

It is durable, deliberate memory for work between sessions: captured context, decisions, progress, artifact references, unresolved questions, and resumption state. It is not automatic transcript harvesting.

Does Session Save upload or read hidden transcripts?

No. Capture is deliberate and user-invoked. Session Save writes context available in the current client to local files; it has no product uploader or background transcript collector.

Can I choose where records live?

Yes. The default is ~/Desktop/session-logs/, and the installer accepts another local home. Existing homes never move automatically.

Were the old skill names removed?

No. session-checkpoint, session-close, and session-review are additive wrappers. session-save, session-summary, session-audit, and their short aliases remain installed.

Does Review decide project truth?

No. It groups only approved deterministic project identities, cites each source, exposes contradictions, and leaves unknown labels separate. It cannot update a master plan.
