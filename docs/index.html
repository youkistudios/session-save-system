01 / FOUR MOMENTS

A small command for every state change.

Tag

Name what the session actually became. Capture gist and assets. Decide whether the core work is finished, live, or stale.

Append the current state, next move, and watch-outs. If it runs first, create one provisional index row—not a guessed verdict.

03 / SAFETY

Your records are not installer debris.

Exact identity

Installed files receive SHA-256 manifest entries. Product words inside a file are never treated as ownership proof.

Recoverable replacement

Previously managed files are copied to a timestamped backup before an update replaces them.

Proof before removal

Uninstall removes only allowlisted regular files whose current hash still matches. Modified files survive.

Separate data boundary

The log home and backup tree are never uninstall targets. User data stays user-owned.

HONEST LIMIT

The system can preserve the context a host makes available. It cannot reconstruct missing history, guarantee a model summary is correct, or automate chat controls the host does not expose.
