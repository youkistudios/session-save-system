Session Save

Pick up where
you left off.

Session Save is a local session-memory system. It creates a handover record with the context, decisions, file references, open work, and next steps worth carrying into another session.

In a new Claude or Codex session, run Pickup, choose the project and saved session, review the cited handover, and confirm where to continue. Session Save never watches every chat or loads memory automatically.

INSTALL

One-time Terminal setup for both apps.

git clone https://github.com/youkistudios/session-save-system
cd session-save-system
./install.sh

v2.0.0-alpha.5 · requires Terminal + Python 3 · 41 automatic checks · installed on macOS · Linux testing is not finished

Not comfortable with Terminal? Ask a technical helper to do the one-time setup. Daily use is four deliberate workflow moments, plus Pickup when you need to resume. Session Save has no product cloud or background uploader, and it does not encrypt your notes. After disclosure and consent, Pickup sends only the selected notes to your active AI provider. Your folder may also sync through another service you configure.

Safety modelArchitectureEvidence

Seven clear answers.

What does Session Save remember?

It can remember what happened, what you decided, where the work stopped, which files matter, what remains open, and what should happen next. It saves file names and paths, but it does not copy every referenced file into the memory folder.

How do I pick up in another app?

Run /session-pickup in Claude Code or $session-pickup in Codex. Choose the exact project and saved session. Pickup shows which notes it would read, warns when they came from another AI client, and waits for consent. It then gives you a cited handover and asks before acting. This is user-confirmed resumption, not automatic continuation.

Does it record every chat?

No. You decide when to Tag, Checkpoint, or Close. Session Save does not secretly read old chats or run a background recorder.

Where are my notes kept?

The normal folder is ~/Desktop/session-logs/. You can choose another folder before installing. Session Save never moves an existing memory folder without asking.

Which command names should I use?

Use session-checkpoint, session-close, session-review, and session-pickup. Older save, summary, audit, and short names still work. If another Claude command already uses the same name, Session Save leaves it alone and keeps its skill available through the Skills menu.

Can it mix up two projects?

Session Save only joins notes when you choose the same saved project. Similar words or topics are not enough. Unknown project names stay separate for you to review.

Can I trust every saved summary?

Treat it like any AI-written note: check important details. Session Save keeps the note and its source, but it cannot guarantee that an AI summary is complete or correct.
