01 / FOUR MOMENTS

A small command for every state change.

Name what the session became. Capture client, gist, and assets. Decide whether the core work is finished, live, or stale.

03 / SAFETY

Two writers. No shared-file gamble.

Namespaced records

Claude and Codex never write the same source directory. Client identity is mandatory; model identity is optional.

Atomic global views

A local lock serializes mutations. The index is rebuilt from source envelopes and replaced atomically.

Copy-first migration

Legacy records move only by explicit dry-run and copy. Originals and migration receipts remain.

Proof before removal

Separate SHA-256 manifests govern adapter files. Config, records, migrations, and backups are never uninstall targets.

HONEST LIMIT

The tested kernel supports Claude Code and Codex records. Live client capabilities still vary: the system cannot reconstruct missing history, guarantee a model summary, or automate chat controls a host does not expose.
